# Artefato 10 — Roteiro operacional do GitHub

1. Criar as labels do UC03 conforme o plano.
2. Criar a Issue Epic com o título `[UC03] Processar Pagamento de Mensalidade`.
3. Criar SUB-01 a SUB-07 como Issues vinculadas ao Epic.
4. Registrar dependências nas Sub-Issues.
5. Adicionar todos os itens ao Project do UC03.
6. Configurar os status metodológicos.
7. Mover Epic, SUB-01, SUB-02 e SUB-04 para `Ready`.
8. Manter as demais em `Backlog`.
9. Após a implementação, anexar build, testes e migration como evidências.

Não registrar tokens, credenciais ou dados sensíveis nas Issues.
