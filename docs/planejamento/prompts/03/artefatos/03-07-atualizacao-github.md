# Artefato 07 — Plano de atualização do GitHub

1. Conferir a existência da Epic do UC03 e das Sub-Issues SUB-01 a SUB-07.
2. Confirmar o usuário GitHub de Vitor antes de atribuir qualquer Issue.
3. Atribuir responsáveis e revisores distintos conforme a matriz de distribuição.
4. Publicar o comentário correspondente do Artefato 05 em cada Sub-Issue.
5. Registrar a revisão humana e aplicar os ajustes solicitados.
6. Usar somente os cinco estados do Project: `Backlog`, `Ready`, `In Progress`, `In Review` e `Done`.
7. Manter todas as Sub-Issues em `Backlog` até DoR-01 a DoR-07 serem atendidos.
8. Promover para `Ready` apenas Issues com assignee, revisão humana e comentário de aprovação.
9. Não criar labels de status, como `status:ready` ou `status:in-progress`.
10. Auditar dependências, rastreabilidade e coerência do board.
