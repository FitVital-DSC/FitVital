# Artefato 3 — Issue principal

## Título

`[UC06] Montar Plano de Treino`

## Objetivo

Planejar a implementação da montagem de uma ficha de treino pelo Personal Trainer, vinculada ao Aluno.

## Escopo

Abrange domínio, contratos, serviço de aplicação, persistência, interface e testes futuros. O M4 não define campos, exercícios, regras de edição, endpoint ou autorização; essas decisões devem ser aprovadas antes da implementação.

## Sub-Issues

- [ ] SUB-01 — Refinar domínio da ficha de treino
- [ ] SUB-02 — Definir contratos e autorização
- [ ] SUB-03 — Implementar serviço de montagem
- [ ] SUB-04 — Implementar persistência da ficha
- [ ] SUB-05 — Expor a interface do caso de uso
- [ ] SUB-06 — Validar automaticamente o UC06
- [ ] SUB-07 — Consolidar decisões e rastreabilidade

## Aceite geral

Uma ficha válida deve ser montada pelo Personal Trainer e ficar vinculada ao Aluno conforme contrato aprovado; entradas inválidas e falhas devem ser explícitas.
