# Artefato 10 — Roteiro operacional do GitHub

1. Criar a label `uc04-matricula`.
2. Criar a Epic e as sete Sub-Issues.
3. Vincular as Sub-Issues como filhas da Epic.
4. Adicionar todos os itens ao Project UC04.
5. Registrar dependências e comentários técnicos.
6. Confirmar responsáveis e revisores.
7. Manter os itens em `Backlog` até a DoR ser satisfeita.
8. Registrar no artefato 13 as URLs reais e o estado do board.

Não registrar tokens ou credenciais nas Issues.
