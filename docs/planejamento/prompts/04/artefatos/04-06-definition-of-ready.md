# Artefato 18 — Definition of Ready

Nenhuma Sub-Issue deve ser promovida para `Ready` antes de assignee confirmado, contratos fechados e revisão humana registrada.

| Critério | Situação atual |
|---|---|
| Objetivo definido | Atende |
| Escopo delimitado | Atende com pendências de contrato |
| Aceite verificável | Parcial |
| Dependências identificadas | Atende |
| Informações disponíveis | Não atende para campos/API/transação |
| Responsável definido | Pendente de confirmação |
| Revisão humana concluída | Não atende |

**Recomendação:** manter Epic e SUB-01 a SUB-07 em `Backlog`.
