# Artefato 10 — Roteiro operacional de configuração no GitHub

1. Acesse o repositório FitVital no GitHub.
2. Crie a Issue principal com o título `[UC02] Realizar Check-in (Controle de Acesso)`.
3. Cole o conteúdo do Artefato 3 e aplique `uc02-check-in`, `feature` e `priority:high`.
4. Crie as oito Sub-Issues com os títulos e corpos do Artefato 4.
5. Vincule as Sub-Issues à Epic por tasklist e, após a criação, substitua `SUB-XX` pelas referências `#<número>`.
6. Aplique as labels conforme o Artefato 7.
7. Crie um GitHub Project Kanban para o UC02.
8. Configure o campo Status exclusivamente como `Backlog`, `Ready`, `In Progress`, `In Review` e `Done`.
9. Adicione a Epic e as oito Sub-Issues ao Project.
10. Distribua os itens conforme o Artefato 8.
11. Atribua Mariana Veiga e Vitor Thomé somente após definir a alocação individual.
12. Revise dependências, critérios, referências e rastreabilidade.
13. Confirme que nenhuma Issue está em `Done` nesta etapa de planejamento.

Este roteiro não cria código, branches, commits, Pull Requests ou merges.
