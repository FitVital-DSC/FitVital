# Artefato 07 — Plano de atualização do GitHub

1. Conferir [Epic #12](https://github.com/FitVital-DSC/FitVital/issues/12) e Sub-Issues #13–#20 no repositório.
2. Confirmar a proposta de distribuição: Mariana em SUB-01/03/05/07; Vitor em SUB-02/04/06/08.
3. Atribuir os assignees reais nas Issues; não atribuir usuários sem confirmação.
4. Registrar o revisor no comentário de cada Issue conforme o Artefato 05.
5. Publicar o comentário técnico correspondente e aguardar a revisão humana.
6. Corrigir descrições, critérios e dependências conforme os apontamentos aprovados.
7. Configurar o Project com exatamente `Backlog`, `Ready`, `In Progress`, `In Review` e `Done`. O estado atual `Todo` deve ser ajustado antes de considerar conformidade.
8. Manter todas as Issues em `Backlog` até DoR-01 a DoR-07 serem atendidos e a aprovação humana registrada.
9. Promover para `Ready` somente Issues aprovadas pelo respectivo revisor.
10. Não criar labels `status:ready`, `status:in-progress` ou equivalentes; o estado pertence ao campo Status do Project.
11. Auditar o board, assignees, revisores, comentários e rastreabilidade com o Epic.

Nenhuma etapa deste plano cria código, branch, commit ou Pull Request. A equipe deve registrar decisões sobre lock, limite do personal e RN03/RN04 antes de iniciar implementação.
