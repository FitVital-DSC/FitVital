# Artefato 07 — Plano de atualização do GitHub

1. Conferir a Epic [#21](https://github.com/FitVital-DSC/FitVital/issues/21) e as Sub-Issues [#22–#29](https://github.com/FitVital-DSC/FitVital/issues/22).
2. Confirmar com Vitor o usuário GitHub antes de atribuir qualquer Issue.
3. Confirmar a distribuição proposta e atribuir assignees distintos dos revisores.
4. Publicar o comentário correspondente do Artefato 05 em cada Sub-Issue.
5. Realizar a revisão humana e registrar o template de conclusão.
6. Corrigir descrições, critérios e dependências conforme os ajustes aprovados.
7. Usar o campo `Status Metodologia` com exatamente `Backlog`, `Ready`, `In Progress`, `In Review` e `Done`.
8. Manter as Issues em `Backlog` até DoR-01 a DoR-07 serem atendidos.
9. Promover para `Ready` somente Issues com revisão humana registrada.
10. Não criar labels `status:ready`, `status:in-progress` ou equivalentes.
11. Auditar assignees, revisores, comentários, dependências e rastreabilidade.

Nenhuma etapa deste plano implementa código, cria branch ou abre Pull Request.
