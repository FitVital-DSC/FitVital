# Artefato 11 — Checklist de validação

- [ ] A Epic usa o título `[UC02] Realizar Check-in (Controle de Acesso)`.
- [ ] A Epic referencia formalmente o Blueprint.
- [ ] Existem pelo menos 5 Sub-Issues tecnicamente justificadas (há 8).
- [ ] Não existem tarefas artificiais separadas por fases de TDD.
- [ ] Cada Sub-Issue possui critérios objetivos e verificáveis.
- [ ] RN01 e RN02 estão cobertas.
- [ ] Fluxo principal e os dois fluxos alternativos estão cobertos.
- [ ] Entrada, liberação, bloqueio, registro e incremento estão rastreados.
- [ ] Dependências entre UC02, UC01 e UC03 estão documentadas sem inventar contratos.
- [ ] Protocolo da catraca e mecanismo de concorrência estão marcados como pendências.
- [ ] Labels foram definidas e aplicadas consistentemente.
- [ ] O Project usa exatamente `Backlog`, `Ready`, `In Progress`, `In Review` e `Done`.
- [ ] O estado inicial é predominantemente `Backlog` ou `Ready`.
- [ ] Responsáveis foram confirmados ou permanecem `A definir`.
- [ ] A matriz liga requisitos, Sub-Issues, aceite e verificações futuras.
- [ ] Não foram incluídas regras de saída ou comportamentos não documentados.
- [ ] Nenhum código, branch, commit, PR ou teste executado foi produzido.
