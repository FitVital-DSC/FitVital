# Artefato 10 — Roteiro operacional de configuração no GitHub

1. Acesse o repositório FitVital no GitHub.
2. Crie a Issue principal com o título `[UC01] Solicitar Agendamento de Treino`.
3. Cole na Issue o conteúdo do Artefato 3 e aplique `uc01-agendamento`, `feature` e `priority:high`.
4. Crie uma Issue para cada SUB-01 a SUB-08 usando os títulos e textos do Artefato 4.
5. Em cada Sub-Issue, mantenha objetivo, origem, aceite, dependências, responsável, estado e evidências.
6. Aplique as labels do Artefato 7 em cada Issue.
7. Edite a Issue principal e vincule as Sub-Issues por tasklist; depois substitua os identificadores provisórios por referências `#<número>` quando o GitHub atribuir os números.
8. Acesse a área Projects e crie um Project Kanban para o planejamento do UC01.
9. Configure o campo Status exclusivamente como `Backlog`, `Ready`, `In Progress`, `In Review` e `Done`.
10. Adicione a Epic e todas as Sub-Issues ao Project.
11. Distribua os itens nos estados iniciais do Artefato 8.
12. Atribua Mariana Veiga e Vitor Thomé conforme decisão da equipe; não atribua responsáveis sem confirmação.
13. Revise labels, links, dependências e tasklist.
14. Confirme que nenhuma Issue está em `Done` e que a rastreabilidade com o UC01 está completa.

Este roteiro configura o planejamento futuro; não cria branches, commits, Pull Requests nem implementa código.
